Bind a wallet to MCAgents

This page is served by the mod on your own machine and closes itself when you are done.

MCAgents will never ask for your Secret Recovery Phrase or a private key. This page asks MetaMask for one signature per address. A signature proves you control that address — it authorises nothing, moves no funds, and never reaches a chain. If any page ever asks you for a recovery phrase, close it.

You will be asked to sign one message per address. Each names the address it proves, so one signature can never stand for another.

Every address MetaMask shares with this page will be bound.
