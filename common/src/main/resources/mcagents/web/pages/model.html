Embedding model

Turns questions and packs into vectors, so the mod can find the content that matches what you asked.

Off means questions are sent on their own: no Knowledge Packs are used, and nothing is charged for embedding them. You can still chat exactly as before.

⚠ Changing this changes which vector space new embeddings live in. Packs embedded with a different model are not comparable with these, so a change here really means re-embedding your library.
