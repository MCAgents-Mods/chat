OpenRouter and direct APIs

API keys

The keys this mod uses to answer your questions, and where each one is sent. Stored on this machine only.

🔑 A stored key is only ever shown shortened, here and in the game. Keep the full value to yourself — anyone who has it can spend your credit.
🔒

Add a key

The mod uses the oldest working key for the platform a question is routed to, and moves on to the next when one is rejected.

Where each platform is called

A platform is called directly when it has an address and you hold a key for it. Everything else goes through OpenRouter, which is how the mod has always worked. Clear a box to go back to the built-in address.

An address must be an https address, or a loopback one for a gateway you run yourself.
